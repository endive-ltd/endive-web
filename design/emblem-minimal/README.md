# Endive minimal marks (round 9)

Five one-colour emblems for a tech company, drawn only from circles and straight cuts with one
gap width (7 units in a 200-unit box), so each is exact and holds up at 16 px.

- `final.py`: the five marks plus their construction circles. Run: `pip install shapely numpy && python3 final.py OUT_DIR`.
- `marks.py`, `marks2.py`: earlier sketches kept for reference (most were dropped).
- `svg/endive-mark-<id>[-white|-black|-mint].svg`: final files.
  - `twin`: Twin Leaves (recommended): two leaves from one root, overlap cut out as the stem; four circles.
  - `tile`: Leaf Tile, `kernel`: Kernel, `breakout`: Breakout, `layered`: Layers.

The live brand pack is unchanged.
